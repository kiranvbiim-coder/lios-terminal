**Original source:** `ginlix-ai/LangAlpha@941ca4a18f5a364caf481a6f78cdb040086aa38d` (Apache-2.0). `src/ptc_agent/agent/middleware/background_subagent/workflow/validation.py`, blob `fa516a1615592c66247e13c14d5d8df67886abf4`, selected `parse_schema_result`, candidate cap and fail-closed/retry diagnostics. The controlled fork remains source provenance, not an installed agent framework.

**Product code:** `src/server/langAlphaModelReplyParser.ts` implements bounded scanning for up to 32 JSON candidates, no raw exception/data echoes, object depth and length caps, escaped quote/brace handling and safe selection of the `steps` plan or `decision` review JSON object. `src/server/agentLoop.ts` now calls this parser before the preexisting strict Zod plan/review validator. This fixes brittle first-open-brace/last-close-brace extraction for local models that wrap an otherwise valid response in unrelated Markdown/prose. A bounded malformed response follows the existing GM revision budget, approval/cancellation and ledger lifecycle; no model is allowed to approve itself or gain tools.

**Complete selected mechanism boundary:** Retain useful response parsing, candidate attempt limits, secret-safe error diagnostics and fail-closed reply errors. Do not import donor JsonSchema validator engine, Python runtime, QuickJS evaluator, subprocess executor, alternative agent delegation, memory store, provider network or workflow scheduler. Those duplicate canonical GM/P7/P13 authorities; future LangAlpha long-lived thesis integration needs a different, separately tested coherent package.

**Regression:** source adapter tests include surrounded/fenced JSON, escaped and nested content, many invalid braces, oversized model output, overly deep structured JSON, and no raw secret propagation. Existing agent-loop test exercises the real goal-plan-act-review user journey and bounded revision. Native `node --import tsx --test server/langAlphaModelReplyParser.test.ts server/agentLoop.test.ts`, additional GM conversation integration regression and `npm run check` required. Target packaged acceptance remains separate and the full LangAlpha agent runtime is not installed.
