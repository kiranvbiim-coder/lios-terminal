# LiOS donor websites and repository import gap audit — 2026-10-27

**Decision: NOT all planned donor capabilities are imported or release-accepted.**

**Upstream currency note:** Perspective’s official 2026 documentation now uses `@perspective-dev/*` and its current upstream is `perspective-dev/perspective`; legacy `@finos/perspective-viewer` packages have been deprecated. assistant-ui documents an `ExternalStoreRuntime` explicitly intended for existing app-owned state. The audit checks current package names and recommends reuse of LiOS Chat state, not a default Assistant Cloud import. Review the exact upstream commit and changelog again before import; registry pins are historical and not auto-updated. Continue only against verified gaps in the existing LiOS owner; do not create another agent, UI shell, data catalog, Chart Artifact authority, consulting/marketing service or duplicate renderer. The 92 canonical baseline donor entries are **not** a goal to install 92 packages. Some are intentionally reference-only, rejected, separate service runtimes, or optional.

**Basis:** verified baseline on `main` (`47cc7a8f2f480af97f8c64bd8b2fe7a1e04c7277`) and the active Phase 4 branch donor registry (identical baseline truth files at inspection); `third_party/capability-assimilation.json`, `third_party/universal-donor-adoption.json`, `third_party/components.json`, `third_party/controlled-fork-utilization.json`, `third_party/upstream-lock.json`, `src/package.json` + npm lock and selected actual client/server source files. This is a **metadata, dependency and source-path audit**, not a full upstream source-tree audit, package bootstrap or native installed acceptance.

## Reproduce the exact 92-entry gap report

From `src/` run `npm run audit:donors:gaps`. The read-only command emits JSON containing every donor's repository, canonical owner, status, source pin presence, registered path count, direct locked dependency check for selected named packages, local target-path presence, next evidence, full audit/packaged claims and work group. `node --test script/donor_gap_audit.test.mjs` checks no phantom adoption claims, path/lock handling, license exclusion and the exact baseline.

**Status tally from the baseline:** 7 runtime-integrated; 4 optional runtime; 4 partial; 1 connector; 1 integrated external provider; 43 documented-only; 15 reference-only; 8 discovered; 2 standard-compatible (without donor SDK); 1 bridge-only; 1 deferred contract; 5 rejected = **92**. The universal ledger's `allDonorsIntegrated`, `allForksIntegrated` and `shippingPointsAcceptedByThisRecord` flags are all false; all 92 donors show `fullPackageSourceAuditComplete=false` and `packagedShippingPointAccepted=false` there. **These records do not mean nothing runs**; they mean a donor catalog/fork is not acceptance evidence.

### P4 Perspective gap confirmed against the real incumbent

At this audit SHA the existing `src/client/src/components/terminal/ArtifactChartRecordedTable.tsx` renders **all recorded exact chart series**, with accessible **40-row paging**, no synthetic zero interpolation and independent chart zoom; `ReadableValueTable.tsx` renders canonical recorded scalar/scenario rows; `ChatTableBlock.tsx` provides safe, scrollable copyable answer tables; `ArtifactPane.tsx` is the canonical P4 owner. These **must not** be replaced. The narrowly missing donor candidate is an **opt-in interactive large-dataset pivot/aggregation/streaming grid** with provenance and explicit user intent; it is not a generic replacement for existing saved chart/document tables.

**Next contributor task:** inspect `perspective-dev/perspective` at the recorded source pin; compare `@perspective-dev/client`, `@perspective-dev/viewer`, `@perspective-dev/viewer-datagrid`, and React wrapper with the existing P4 data Artifact contracts and worker/CSP/desktop constraints. Since `@finos/perspective-viewer` is deprecated, do **not** add deprecated packages from old donor notes. Select **one small lazy renderer** only if real tabular pivot/filter features exceed the current paged table without losing provenance/null semantics. Never write transformed projections back into recorded source data; do not unlock unentitled provider records or increase default bundle/native footprint without measurement.
