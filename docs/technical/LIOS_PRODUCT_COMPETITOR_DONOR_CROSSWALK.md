## 1. Locked product: one universal LiOS, not a finance-only chatbot

LiOS is one user-owned, conversation-first **generative AI + governed agent + research + professional-work + deterministic Finance + automation + distributed-device** product. The existing full Dockview Financial Workbench is its professional interface—not a second application, new terminal or disabled legacy feature. Default signed-in viewport is quiet Chat. Contextual Artifact sidecar and explicit Expand Workspace present the same canonical object. Both must preserve user/tenant, Chat/Project/Temporary posture, P5 company/security identity, permitted sources/entitlements, temporal/unit/currency/assumption context, P4 Artifact/revision, proof receipts and view layout. Retained Quick Chat artifacts must never require a forced Project; Temporary remains nonpersistent.

General-use prompts must work without a finance ticker or a Project: ask, write, edit, research, compare, code, operate tools, analyze data, create and revise reports/documents/tables/charts/slides, use images/docs and reviewed voice, remember permitted context, schedule follow-ups and recover safely. Finance has eleven accepted capability families plus institutional depths; AI does not silently become calculator of record. Both worlds use the same local-first Home, identity, GM execution, P5 sources/entities, P11 calculations, P4 Artifacts, TC UX and P9 automations.

**Critical omission recovery:** [General Gen AI requirements](../LIOS_EXECUTION_ROADMAP.md) §0.0.12/§0.0.13, [BYOAI entitlement directive](OPENCLAW_AI_ACCESS_ASSIMILATION_DIRECTIVE.md), [live model acceptance](LIVE_AI_PRODUCT_ACCEPTANCE.md), [P12 voice/multimodal](P12_VOICE_MULTIMODAL_SPEC.md), [P13 plugin SDK](P13_PLUGIN_SDK_SPEC.md), [visual environments](../ux/VISUAL_ENVIRONMENT_PRODUCTION_BRIEF.md), and [Finance competitive matrix](LIOS_FINANCE_COMPETITIVE_CAPABILITY_MATRIX.md) are part of the same approved product. Do not omit them from shipping proof merely because SI labels are broad.

**BYOAI is bring-your-own legitimate AI entitlement**, not only keys. Where officially permitted, include account/OAuth/subscription access, provider-native CLI, free/trial, API, enterprise gateway and self-hosted/local models; separate provider/model/runtime/account profile/entitlement/capability/consent/cost/route. Detect existing access safely; forbid cookie extraction, unsupported subscription claims, rate/quota evasion, implicit meter spending and a LiOS-operated routine customer inference cloud. Image input/vision is NOT proof of image/video/audio generation: evaluate any additional creative-generation scope explicitly through owner-approved requirements and rights before claiming shipment.
