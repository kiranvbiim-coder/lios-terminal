## Evidence and release gate

1. Exact PR #318 head must finish **Linux, Windows and macOS** source jobs successfully. Old cancelled/queued runs do not qualify. The frozen sidecar checks only run if its PyInstaller build actually executes; source-unit CI alone does not prove a working frozen executable.
2. Build the Python sidecar on each intended native platform. Require token denial, known-answer statistics, and valid reverse-DCF response from the **frozen** binary. Any packaged valuation HTTP 502 is a blocker, not a pass.
3. Install the actual signed/notarized Electron candidate. Verify app-resources closure, backend launch, sidecar startup, 401 token refusal, quote/news and valuation paths, source grants, permission/revocation, project continuity, 390px/200% responsive keyboard accessibility and low-resource behavior. Capture immutable hashes outside the signed app.
4. Run `npm run check`, `npm run test:offline`, `npm run test:desktop`, `npm run build`, `npm run audit:oss`, `npm run audit:licenses`, and `npm run release:preflight:ci` from `src/` on the exact release candidate.
5. Approve production photo grants only after external permission and source identity checks; the manifest may correctly remain empty until then.
6. **Do not merge to main, sign off or deploy** until the required installed-app, security, privacy, source rights and CI evidence is available.

This reconciliation intentionally keeps one canonical implementation instead of adding a second runtime, overlay manager, style owner or provider stack.
