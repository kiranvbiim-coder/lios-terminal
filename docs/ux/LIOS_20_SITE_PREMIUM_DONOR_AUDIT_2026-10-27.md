## I. Product decision and classification

Owner permits **large-scale open-source source assimilation**, including coherent bundles, dashboard layouts, interaction families, agent UI, complete permissible backend subsystems and framework upgrades if actual integration tests show superior value. **No artificial 1–2 component cap; build last.** The reuse gate remains precise source/license/media/permissions/security/ownership/install quality, not a ban on large imports. This audit distinguishes:
- **CODE** — actual source files available under a verified license, integration feasible after version tests.
- **REFERENCE** — galleries/visual work with **no general reuse license** for displayed creative assets or third-party websites.
- **GENERATOR** — prompts/layouts/hosted project with account restrictions; viewing/creating a demo is not free source export.
- **SERVICE** — API/paid delivery/contract platform; optional BYOD connection, **no forced subscription**.
- **ASSET** — paid/commercial license may permit bundling or use, but separate from code/brand rights.

Product experience: immersive discovery, editable/evidence-grounded analysis, quiet productive Chat/Artifact Workbench, optional high-quality promotional assets. Retain all F01–F12 and N01–N08 from parent plan.

## VI. Donor integration acceptance ledger template

For each imported **component, family or entire system**, record:
- User journey, old LiOS component/owner, explicit visual/function gain; source commit, exact paths, version, required dependencies and individual file/license notices.
- Upstream optional/paid/free status, typography/media license, external domains and fetch permissions; screenshot before/after.
- React/Tailwind/Motion compatibility and a contained upgrade test if justified; refactored imports/styles; minimal retained added dependencies.
- Where authoritative UI state/data comes from: Wave D, P2, P3/P5, P4, P9, P11 or GM; no conflict.
- Source-only typecheck, unit tests, rendered/browser screenshots, installed Electron experience (Mac/Windows), offline/denied/stale cases and performance metrics; do not conflate tests.
- License redistribution review for proprietary bundle, including fonts, imagery, datasets and external API terms.
- Result: **adopted**, **adapted**, **replaced existing**, **deferred**, **rejected with evidence**, plus evidence links.

No unverified demonstration may be marked as feature complete, and no category is excluded merely because source import is large, React19-oriented or visually ambitious. All modifications use reviewed branches, not protected-main direct writes.
