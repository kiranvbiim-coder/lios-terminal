# LiOS UX References

The active product UX contract is [LIOS_UX_SYSTEM.md](../LIOS_UX_SYSTEM.md). This directory contains supporting visual-design references, not a separate UX roadmap or completion tracker.

The [SI execution plan](../LIOS_SUPER_INTELLIGENCE_EXECUTION_PLAN.md) and [Shipping Point contract](../technical/SUPER_INTELLIGENCE_SHIPPING_POINT_CONTRACT.md) govern delivery through existing TC/GM/CA/P owners; S0–S10 are validation coverage, not execution headings. The supplied Figma graphite/gold, Barlow Condensed display/Inter prose/JetBrains Mono data and matte new/unconfigured default supersede older orange/cinematic/Inter-display/mandatory Neutral directions. The ten environments and three intensity states remain optional; explicit saved choices are retained.

## Verification boundary

`npm run validate:visual-environments` checks static source contracts and visual asset presence. It does not establish that the interface was rendered, visually reviewed, exercised interactively, or verified in a packaged desktop app. Report those checks separately and only after they are actually run.

Human aesthetic sign-off is also bounded evidence, not P14 release certification. SP-01–SP-07 require real MSJs, applicable target execution, no fake success, regression protection and exact build/environment/journey/outcome/limitations records. Screenshots, source presence and unsigned smoke cannot be promoted to Shipping Point acceptance or signed release proof; this index asserts neither.
